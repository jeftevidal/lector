# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Lector, please do not open a public issue.

Report it privately via GitHub Security Advisories or contact the repository owner directly (`@jeftevidal`). Include steps to reproduce and any relevant logs or environment details.
